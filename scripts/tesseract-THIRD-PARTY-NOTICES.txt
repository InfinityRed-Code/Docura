Tesseract OCR as bundled with Docura PDF
========================================

This folder contains Tesseract OCR and the libraries it needs at runtime. It
is NOT part of Docura PDF and is NOT covered by the Docura PDF license
(PolyForm Noncommercial 1.0.0 / commercial license). Everything in this
folder is distributed under its own licenses, listed below; their full texts
are in the licenses\ subfolder.

Docura PDF only starts tesseract.exe as a separate program (command line in,
text out). It does not link, load or include any file of this folder.

All files are distributed unmodified, as built by their original publishers.

Origin
------
Windows build of Tesseract 5.4.0 by UB Mannheim, release v5.4.0.20240606
(https://github.com/UB-Mannheim/tesseract), cross-compiled with MinGW-w64
against MSYS2 packages. The libraries are the MSYS2 (MINGW64) packages
listed below. Language models deu and eng from tessdata_fast, tag 4.1.0
(https://github.com/tesseract-ocr/tessdata_fast). Only tesseract.exe, the
DLLs it loads, tessdata\configs and the two language models are included.

Source code (written offer)
---------------------------
The complete corresponding source code for this folder is published with
every Docura PDF release that ships it, as the release asset

  docura-pdf-tesseract-sources-5.4.0.20240606.zip

on the release page of that Docura PDF version:

  https://github.com/InfinityRed-Code/rustpdf/releases

It contains the Tesseract source at the UB Mannheim tag (with UB Mannheim's
build scripts) and, for every library above except the GCC runtime and
winpthreads, the MSYS2 build recipe (PKGBUILD and patches) together with
the upstream source it builds, including JBIG-KIT, GNU libiconv, LibTIFF and
Leptonica. Its README.txt says where the GCC runtime and winpthreads source
is, and SHA256SUMS.txt lists a checksum for every file. The archive stays
available there for at least three years after the last Docura PDF release
that ships this Tesseract bundle, at no charge.

Upstream projects:
  Tesseract     https://github.com/tesseract-ocr/tesseract
  JBIG-KIT      https://www.cl.cam.ac.uk/~mgk25/jbigkit/
  GNU libiconv  https://www.gnu.org/software/libiconv/
  LibTIFF       https://libtiff.gitlab.io/libtiff/
  Leptonica     http://www.leptonica.org/
  MSYS2 recipes https://github.com/msys2/MINGW-packages
